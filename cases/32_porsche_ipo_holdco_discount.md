# 案例 32：Porsche AG 上市與 Porsche SE 控股折價（2022-09 ～ 2026）

> **一句話**：Porsche AG 以 82.5 歐元上市，只有 12.5% 股本流通，卻靠「快速納入」81 天就進 DAX；三年後股價比 IPO 價低約 45%，又因自由流通市值太小被剔除。母公司 Porsche SE 的股價則長期比自己持股的淨值低三到四成，折價不收斂。

| 項目 | 內容 |
|---|---|
| 接縫 | (1) 指數只看自由流通市值：小流通量的大公司上市時可以快速納入，股價一跌又最先被剔除，被動資金在兩個方向都被迫交易；(2) 控股公司的淨值（NAV）以市價計，但股東拿不到持股，只拿到控股公司層的股利與負債，NAV 折價沒有制度性的收斂機制 |
| 強制流來源 | DAX 快速納入（2022-12-19）與剔除（2025-09-22）時，追蹤 DAX 的被動資金買進／賣出 Porsche AG 特別股 |
| 量級 | IPO 估值約 750 億歐元；Porsche SE 以 101 億歐元買下 Porsche AG 25% + 1 股普通股；Porsche SE 淨值 2026-09-30 約 124 億歐元，折價 37% |
| 不看價格的一方 | 追蹤 DAX 的被動基金；IPO 時的基石投資人 |
| 天然對手方 | 在納入前買進、納入日賣給被動資金的人；剔除時承接的 MDAX 追蹤資金與主動資金 |
| 規則風險 | 低：指數規則公開；控股折價則受 Porsche SE 負債與 VW 股價影響，沒有外力會強制收斂 |
| 查證狀態 | ✅ IPO、DAX 納入與剔除、Porsche SE 2023／2024／2026-09 折價對公司或兩個來源；⚠️ 2022 年（IPO 時）的折價率未找到（見第 5 節） |

## 2. 機制

制度層一：DAX 依自由流通市值排序，並設有「快速納入」條款，讓大型新股不用等定期審核（[Porsche 新聞室](https://newsroom.porsche.com/en/2022/company/porsche-ag-initial-public-offering-inclusion-german-share-index-dax-30570.html)）。Porsche AG 只有特別股上市、自由流通約 12%，所以排名對股價特別敏感：股價高時靠總市值撐住，股價一跌最先掉出（[XTB](https://www.xtb.com/en/market-analysis/de40-porsche-bids-farewell-to-dax-german-industry-weakens)）。制度層二：Porsche SE 的淨值等於所持 VW 與 Porsche AG 的市值減去淨負債；控股折價（holding discount）是淨值與市值的差距，Porsche SE 自己在年報裡定義並每季公布（[2024 年報](https://porsche-se.com/fileadmin/downloads/investorrelations/mandatorypublications/annualreport-24/PSE2024_Annual_Report_en.pdf)）。股東無法把 Porsche SE 股票換成底層持股，Porsche SE 也不會為了消除折價而出售 VW 控制權，所以折價沒有強制收斂的機制。法規與誘因層：Porsche SE 為了買 Porsche AG 股份背負約 67 億歐元淨負債（2022 年底，見 [Porsche SE 新聞稿](https://www.porsche-se.com/en/media/press-releases/pdf/porsche-se-steigert-konzernergebnis-nach-steuern-auf-48-milliarden-euro)），負債放大了它對 VW、Porsche AG 股價下跌的敏感度。

## 4. 我的解讀（草稿，待討論）

1. **小流通量的大型新股，指數納入與剔除是同一個接縫的兩端。** 快速納入讓被動資金在上市後很快成為買方（納入前股價比 IPO 價高 14%），但同樣的自由流通規則，讓它在股價下跌時最先被剔除。對 prop desk，任何「總市值大、流通量小」的新股，納入日和潛在剔除日都可以事先列入觀察，而且兩邊的強制流方向相反。
2. **控股折價是結構，不是錯價。** Porsche SE 的折價三年都在 35%–39% 之間，沒有收斂。折價要收斂需要一個催化事件（清算、分拆、轉換、大額回購），本案三年內都沒有。跟封閉式基金或 GBTC 轉 ETF 的案例比，差別就在有沒有「轉換路徑」。沒有轉換路徑的 NAV 折價，只適合做配對（多 Porsche SE、空 VW），不適合單邊押收斂，而且配對還要扛 Porsche SE 自身的負債。
3. **IPO 定價時的「錨定買家」不等於長期支撐。** Porsche SE 以 IPO 價溢價 7.5% 買普通股、綠鞋在 10 月初護盤，但股價三年後跌掉 45%。上市初期的支撐全部來自有期限的機制（綠鞋、指數納入），機制結束後，價格回到基本面（關稅、電動車需求、中國銷售）。

## 5. 限制與未證實

- 原手冊寫「Porsche SE 與 VW 相對其持股資產淨值長期折價」：Porsche SE 有公司公布的控股折價；VW 本身是營運公司，不適用「相對持股淨值折價」的說法，本文刪除 VW 部分。
- 2022 年底（IPO 當時）的 Porsche SE 控股折價率未找到公司公布數字。2022 年年報與 2023-01 投資人簡報本次都未取得這個數字，因此沒有 IPO 時點的折價率。
- 第三方曾寫「2025-12-31 折價 31%」「2026-03-31 折價 33%、淨值 142 億歐元」「2026-06-30 約 34%」，本次只在搜尋摘要中看到、公司頁面現已更新為 2026-09-30 數字，未能直接核對，未寫入。
- 第一天收盤價各來源不同：RTÉ 寫 82.50 歐元、Spokesman-Review（AP）寫 82.62 歐元；兩者都是平盤附近。
- IPO 募資金額各來源不同（94 億歐元公開發行 vs 195 億歐元含 Porsche SE 交易），本文未採用。
- Porsche AG 的股價數字來自 Yahoo Finance 月資料（XETRA，P911.DE），只用於月收盤與月高低，非交易所一手資料。
- 原手冊稱「歐洲最大 IPO 之一」：多家媒體稱為「歐洲十年來最大」或「德國 25 年來最大」，口徑不一，本文未寫。
