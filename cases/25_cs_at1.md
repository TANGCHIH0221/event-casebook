# 案例 25：瑞士信貸 AT1 債券清零（2023-03 ～ 至今）

> **一句話**：UBS 緊急收購瑞士信貸（Credit Suisse, CS）那個週末，瑞士金融市場監理局（FINMA）下令把面額約 165 億瑞郎的 AT1 債券全部註銷，股東卻還拿到 UBS 的股票。兩年半後，聯邦行政法院判這道命令違法，但案子上訴到聯邦最高法院，債券到今天（2026-11）都還是零。

| 項目 | 內容 |
|---|---|
| 接縫 | AT1 契約允許在「生存能力事件」（Viability Event）時註銷（合理）＋ 緊急命令授權監理機關處理危機（合理）→ 監理機關可以在股東之前讓債權人歸零，打破傳統的清償順位 |
| 強制流來源 | 監理命令直接註銷，不經市場 |
| 量級 | AT1 面額約 165 億瑞郎；UBS 以約 30 億瑞郎的股票收購 CS |
| 不看價格的一方 | FINMA（目標是讓 UBS 收購能在週末完成） |
| 天然對手方 | AT1 持有人 |
| 規則風險 | 已經發生；目前在反向發展：行政法院撤銷命令，最高法院審理中 |
| 查證狀態 | ✅ 行政法院判決日、FINMA／UBS 上訴、最高法院停止執行與 2026-03 程序裁定已對法院新聞稿與瑞士媒體；⚠️ 2026-03 之後的進度查不到（見第 5 節） |

## 2. 機制

- **契約與法規**：AT1 的發行條款有兩個觸發條件：資本跌破門檻，或發生「生存能力事件」（包括政府提供特別支持）。FINMA 主張，政府在 3/19 提供流動性支持，構成生存能力事件；另外又有聯邦委員會的緊急命令第 5a 條作依據。
- **行政法院的看法**：它認為生存能力事件沒有發生，因為「註銷時 CS 資本充足、符合監理要求」；銀行法第 26 條、FINMA 法第 31 條、緊急命令第 5a 條都不足以作為依據。而且，初步看來，第 5a 條在幾個面向上違憲。對財產權的嚴重干預，需要清楚的正式法律依據。
- **順位**：正常的清算順序是股東先虧完，債權人才受損。這次反過來：股東拿到 UBS 的股票，AT1 歸零。這是當時市場最震驚的地方。
- **規模**：約 360 件訴訟、約 3,000 名原告，合併成一個多方程序審理。

## 4. 我的解讀（草稿，待討論）

1. **規則制定者是最後的對手方，而且它可以選擇讓誰先虧。** 清償順位寫在法律和契約裡，但危機週末裡，監理機關的目標是「讓收購在週一開盤前完成」。股東的同意（或至少不阻撓）對併購有用，AT1 持有人沒有用，所以順位被反過來。對 prop desk：任何「清償順位保護」都要打折，折數看監理機關在危機時需要誰的配合。
2. **法律救濟的時間尺度遠大於交易的時間尺度。** 從清零到行政法院判違法，花了兩年半；最高法院又給了停止執行，判決時間不明。就算最後贏了，這筆錢的現值也要扣掉多年的資金成本和不確定性。交易員要問的不是「法律上對不對」，而是「多久能拿到錢、由誰付」。行政法院撤銷命令後，誰付錢（UBS 還是瑞士聯邦）又是另一場官司。
3. **跟 LME（案例 16）對照：同樣是規則制定者在危機中重新分配損失，法院的反應卻相反。** 英國法院審程序，支持了 LME；瑞士行政法院審法律依據，撤銷了 FINMA 的命令。這提示，「規則制定者取消／註銷」的事後風險，要看當地法院是審程序還是審實體。這是可以事先就各國比較的。
4. **可量化的問題（留給重建）**：清零之後，其他歐洲銀行的 AT1 價格有沒有因為「監理裁量風險」而長期加價？若有，行政法院 2025-10 的判決公布時，有沒有讓這個加價縮小？

## 5. 限制與未證實

- **原手冊寫「2025 年瑞士聯邦行政法院裁定推翻 2023 年清零命令」，正確**。精確日期是判決 **2025-10-01**、公布 2025-10-14；這是**部分判決**，還沒有處理「恢復原狀」的請求，也沒有命令賠償。
- **原手冊寫「約 170.1 億瑞郎（約 173‒178 億美元）」**。行政法院寫約 165 億瑞郎，FINMA 3/19 新聞稿寫約 160 億瑞郎。本文採用法院的 165 億，170.1 億的來源沒有找到。
- **原手冊寫「瑞士聯邦行政法院收到約 320 件上訴」**，法院自己寫的是約 360 件程序、約 3,000 名原告。
- **原手冊寫「Quinn Emanuel 於 2024/6/7 在紐約南區聯邦法院……（求償全額）」**。實際起訴日是 **2024-06-06**（6/7 是報導日），求償 8,200 萬美元以上，不是全額；這個案子已在 2025-09-30 因主權豁免被駁回，目前在第二巡迴上訴法院。
- **原手冊寫「CS 破產前 3/17 AT1 約以面額 40% 交易（市值約 68 億美元）」**：沒有找到一手來源，本文已刪除。
- **2026-03-16 之後的最高法院進度**：查到 2026-11 都沒有找到判決或開庭日的報導。這是「查不到」，不代表「沒有進展」。
- 「股東拿到約 30 億瑞郎」是 UBS 收購 CS 全部股份的總對價，以當時 UBS 股價計算，不是現金。
