# 案例 21：微軟收購動視暴雪（2022-01 ～ 2023-10）

> **一句話**：每股 95 美元的現金收購，要同時過美國 FTC 和英國 CMA 兩關。CMA 否決當天，ATVI 跌了約 11%；美國法院駁回 FTC 禁制令當天，ATVI 漲了約 10%。最後微軟把雲端串流權賣給 Ubisoft，換到 CMA 放行。價差就是兩個監管機關各自機率的乘積。

| 項目 | 內容 |
|---|---|
| 接縫 | 收購案必須在每一個有管轄權的國家都過關。只要一國否決就破局 → 任何一個市場的監管機關都握有否決權 |
| 強制流來源 | 無機械性強制流；價差由套利者持有，監管消息一出就集中重新定價 |
| 量級 | 交易總額 687 億美元（含淨現金） |
| 不看價格的一方 | 微軟：合約價 95 美元固定 |
| 天然對手方 | 併購套利基金（持有 ATVI、等成交）vs. 押破局的賣方 |
| 規則風險 | 核心就是規則風險：FTC 行政訴訟＋聯邦法院禁制令，加上 CMA 最終報告 |
| 查證狀態 | ✅ 收購價、FTC／CMA／法院日期、完成日已對一手或主要媒體；⚠️ 4/26 收盤價只有盤中數字（見第 5 節） |

## 2. 機制

- **法規（雙重管轄）**：美國 FTC 要阻擋收購，必須說服聯邦法院發出禁制令，舉證門檻高，結果在法院輸了。英國 CMA 則是行政機關自己就能直接禁止，不需要先上法院。兩套程序的強度不對稱，CMA 反而成了最難過的一關。
- **交易設計**：分手費與最後完成期限（7/18）讓微軟有誘因讓步。最後的解法不是打贏官司，而是改交易結構（把雲端串流權拆出去給 Ubisoft），讓 CMA 用「新案」的程序重審。
- **價差行為**：每一次監管節點，價格都跳一大段，不會慢慢反映。

## 4. 我的解讀（草稿，待討論）

1. **併購價差 = 監管與法院機率的定價，而且是相乘。** 美國與英國兩關都要過，成交機率等於兩者相乘。4/26 CMA 否決，折價擴大到約 19%；7/11 美國法院放行，折價縮到約 4%。從價格可以反推，市場在 7/11 之後幾乎已經認定 CMA 會讓步。可交易的訊號是：哪一關的機率最不確定，消息就在哪一關炸。
2. **規則制定者的「形式」比「立場」重要。** FTC 立場強硬，但它必須上法院，最後輸了；CMA 可以直接決定，所以英國雖然只是動視暴雪眾多市場之一，CMA 卻成了最終的對手方。評估跨國併購時，要先畫出每個監管機關「要不要經過法院」的流程圖，再看它的立場。
3. **破局的成本設計決定了誰會讓步。** CMA 否決後，價格沒有跌回宣布前的水準，因為市場預期微軟寧可改結構也要成交。對 prop desk 而言，否決當天的跌幅（約 11%）就是買「買方願意讓步」這個選擇權的價格。這要事先評估：買方有多少可以割讓的資產？

## 5. 限制與未證實

- **CMA 否決當天（2023-04-26）的收盤價沒有一手來源**：Reuters 寫盤中跌近 12% 到 76.65 美元，Trefis 寫「跌 11% 到 77 美元」。原手冊要的「當天跌幅」，本文寫「約 11%（盤中近 12%）」，收盤精確值未證實。
- 宣布日用的是 Reuters 的盤中價 82.10 美元，不是收盤價。
- 原手冊寫「CMA 於 2023/10 放行，交易 2023/10/13 完成」：核准與完成都在 **2023-10-13** 同一天，沒有錯，本文補上了日期。
- 原手冊寫「英國 CMA 最初否決」，正確；但「每次否決／訴訟消息使折價擴大」的說法，FTC 2022-12-08 起訴當天的價格反應本文沒有查證，所以沒有列入。
- 判決的日期：判決書簽署日 2023-07-10，公開與市場反應在 2023-07-11。
- 「Microsoft 若破局要付 30 億美元分手費」只有 Reuters 引述消息來源，沒有對到合約原文，不列入。
