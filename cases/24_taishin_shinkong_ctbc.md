# 案例 24：台新金–新光金合併 vs 中信金競購（2024-04 ～ 2025-07）

> **一句話**：中信金的出價比台新金高，但金控公開收購要金管會在 15 個營業日內准駁。金管會用「補件」暫停計時、再以「緩議」擋下中信金。這場競購最後不是由價格決定，而是由監管的准駁時鐘決定。

| 項目 | 內容 |
|---|---|
| 接縫 | 《公開收購辦法》讓出價高的一方可以直接向股東收購；《金融控股公司法》第 36 條卻要金管會事前核准，而且金管會可以用「補件」暫停計時。價格競爭的規則和監管准駁的規則疊在一起，准駁時鐘比出價更有決定力 |
| 強制流來源 | 兩家換股合併案都有股東臨時會與過戶截止日（2024-09-10 停止過戶），競購方必須在這之前拿到核准，否則來不及影響投票 |
| 量級 | 中信金計畫收購新光金最多 51%，總額約 1,314 億元（現金部分約 360 億元） |
| 不看價格的一方 | 合併基準日前未出場的新光金股東：基準日當天自動依比例換成台新金股票與特別股 |
| 天然對手方 | 押注競價升溫的事件套利者與散戶 |
| 規則風險 | 高：金管會的「緩議」沒有固定標準；本案金管會明確表示金控、銀行、壽險收購以股票作對價「沒有前例」 |
| 查證狀態 | ✅ 收購價、換股比例、金管會處理、合併基準日均對兩個以上來源；價格反應為 FinMind 自行計算 |

## 2. 機制

法規層：金控公開收購另一家金控，要先經金管會核准，金管會須在收件後 15 個營業日內准駁，但要求補件時計時暫停（[科技新報](https://finance.technews.tw/2024/08/28/financial-holding-merger-2/)、[數位時代](https://www.bnext.com.tw/article/80474/ctbc-merge-2024-drama)）。同時，台新新光的合意合併只要雙方董事會與股東會通過，再送金管會審，時程掌握在當事人手上。制度層：中信金用「股票 + 現金」作對價，金管會指出公開收購辦法 2002 年修正以來，收購金控、銀行、壽險都沒有以股票為對價的前例（[中央社](https://www.cna.com.tw/news/afe/202409165006.aspx)）。人性與誘因層：新光金經營層與台新金是合意的一方，中信金是敵意的一方；金管會的四大理由中有一條是對新光人壽財務掌握不足、沒有增資承諾，反映監管者最在意的是壽險子公司的資本缺口誰來補，而不是誰出價高。

## 4. 我的解讀（草稿，待討論）

1. **監管准駁期限就是事件日，「補件」是比准駁更早的訊號。** 09-04 補件函一發，等於告訴市場金管會不打算在過戶截止日（09-10）前放行；中信金的價格優勢在那天就失效了。跟案例 23（德國經濟部用補件停住審查時鐘）是同一個手法：監管者不必正式否決，只要讓時鐘停住。
2. **在台灣，敵意併購的定價要多扣一個「監管偏好」折價。** 中信金條件在 08-23 隱含約 14.46 元，新光金只交易在 12.45 元；市場沒有把較高的出價當成可實現的價格。價差反映的不是資金成本，而是對「金管會偏好合意併購、偏好現金對價」的判斷。對 prop desk 而言，台灣金融業併購套利的核心變數是主管機關的態度，不是出價高低。
3. **價格最大的跳動發生在監管表態日，而不是股東會日。** 新光金最大的單日跌幅在 09-18（緩議後首個交易日 −7.9%），10-09 股東臨時會通過那天只跌 1.2%。股東會是可預期的程序，准駁才是不確定性的來源。
4. **特別股讓換股價差變得難算。** 最終條件含 0.175 股不可轉換、三年後收回的辛種特別股，市場價值低於面額，用面額 10 元把它加進去會高估換股價值。要做這種案子的價差，必須先替特別股估一個折現價。

## 5. 限制與未證實

- 原手冊寫「中信金每股 14.46 元」：中信金公告的是以近三日均價計算約 14.55 元；14.46 元正好等於以 2024-08-23 收盤價計算的隱含價值，兩者口徑不同。
- 原手冊寫「1 股新光金換 0.51–0.56 股台新金」：查無來源。原始比例是 0.6022 股，2024-09-11 改為 0.672 股普通股 + 0.175 股辛種特別股。
- 原手冊寫「中信金公開收購新光金 10%–51%」：上限 51% 有來源；下限 10% 本次未找到一手來源。
- 原手冊寫「金管會最終未核准中信金方案」：方向正確，正式用語是「緩議」（2024-09-16），中信金 09-20 自行停止。
- 金管會核准合併的日期：新聞稿是 2025-03-31 傍晚發布，核准函 04-01 送達，兩者都有報導。
- 本文沒有計算 2024-09 之後的換股價差時間序列，因為台新金在合併期間的除權息可能調整換股基準，FinMind 收盤價需先做除權息還原才能比較。
