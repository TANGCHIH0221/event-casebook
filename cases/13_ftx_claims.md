# 案例 13：FTX 破產與債權交易（2022-11 ～ 2026-07）

> **一句話**：FTX 客戶債權在倒閉後幾週只值 3–12 美分，一年半後漲到超過面額；賺到這段的是有法務與 KYC 能力的不良債權基金，而急著拿現金的散戶債權人把債權賣給他們。債權以 2022-11 申請日的美元計價，所以即使「拿回超過 100%」，也錯過了之後的加密貨幣漲幅。

| 項目 | 內容 |
|---|---|
| 接縫 | 美國破產法以申請日（2022-11-11）價格把加密資產債權換算成美元 × 遺產實際持有的資產（加密幣、創投持股）在破產期間大幅增值 |
| 強制流來源 | 需要流動性或不想等 2–3 年程序的債權人（多為散戶）賣出債權；遺產本身也依程序變現資產 |
| 量級 | 2024-05 修正版重整計畫：可分配 145–163 億美元，對應約 112 億美元債權；2025-02 ～ 2026-07 已分配約 100 億美元以上 |
| 不看價格的一方 | 急需現金、不熟破產程序的債權人 |
| 天然對手方 | 不良債權基金與債權交易平台（Attestor、Baupost、Farallon 等） |
| 規則風險 | 已實現：重整計畫 2024-10-07 獲法院核准，2025-01-03 生效；剩餘爭議為各國客戶的 KYC 與限制地區處理 |
| 查證狀態 | 時程與分配 ✅ 已對媒體報導（多數引述信託或法院文件）；債權價格 ⚠️ 只有報價平台與媒體數字，不是成交紀錄 |

## 2. 機制

- **法規**：破產法把債權固定在申請日。FTX 客戶的比特幣、SOL 等資產，以 2022-11 的低價換算成美元債權；遺產後來賣掉或持有的資產漲了，多出來的錢先付利息，但不會讓客戶「拿回原本的幣」。
- **制度設計**：債權可以轉讓，但要經過 KYC、轉讓通知、法院登記，對散戶來說手續繁瑣、時程不明；對有法務團隊的基金是可以規模化的流程。
- **人性**：倒閉初期資訊極不確定，加上散戶急需流動性，願意以 3–20 美分出場；遺產追回資產（2023-01 已找到 50 億美元）的消息也沒有立刻反映在價格上。
- **資產變現的爭議**：遺產在破產期間以約 64 美元賣出 SOL，2024-05 時 SOL 約 148 美元，部分債權人認為遺產處分時機損害了回收（[Fortune](https://fortune.com/crypto/2024/05/08/ftx-customers-will-get-their-money-back-and-more-but-the-biggest-winners-are-bankruptcy-traders/)）。

## 4. 我的解讀（草稿，待討論）

1. **債權交易的 edge 是「程序能力」，不是「看準 FTX 會還錢」。** 2023-01 遺產已找到 50 億美元，債權價格卻沒動；真正的重估發生在重整計畫數字公布（2024-05）。報酬給的是願意承擔 KYC、法律文件、時程不確定的人。對 prop desk 來說，這類交易的門檻（法務、託管、對手方網絡）本身就是護城河，跟接縫理論說的「誰有能力利用」直接對應。
2. **申請日定價是一把雙面刃。** 對債權買家，它讓回收金額可預測（美元債權 + 利息）；對原始客戶，它讓「拿回 105%」其實低於持幣不動的報酬。這種「名目上全額、實質上錯過」的落差，是散戶願意在低價賣出、事後又不滿的根源。
3. **分配日是可排進日曆的現金流事件。** 每一輪分配金額與日期都事前公告（例如 2026-03-31 約 22 億、2026-07-31 約 9 億），經由 Kraken、BitGo 等平台入帳。這些資金有多少會回流到加密市場買幣，是可以事後用交易所流入資料驗證的問題，本文未做。

## 5. 限制與未證實

- 原手冊寫「2023/10/16 更新後，Cherokee 報價升至 57–73 美分」：57–73 美分是 **2023-12-20** 的報價；2023-10 的成交在 50–53 美分附近。
- 原手冊寫「2023 年初 XClaim 估約 16 美分，私募 OTC 以 15–20 美分收購、預估回收約 50 美分」：16 與 15–20 美分可對到報導；「預估回收約 50 美分」未找到來源，本文刪除。
- 原手冊寫「2024/5 小額債權升至約 118 美分、大額預估 120–140 美分」：查到的是 Claims Market 買價 101%（Fortune）與另一篇報導的 101–112%；118% 是計畫給便利類別的預估回收率，不是債權價格。120–140 美分未找到來源，本文刪除。
- 原手冊寫「2025/5/30 第二輪逾 50 億美元（回收 54%–120%）」：Decrypt 寫 54%–102%，其他報導寫 54%–120%，差異可能來自是否包含便利類別。本文只寫金額。
- 原手冊寫「多數債權人約 105%」：到 2026-07 第五輪後，客戶類別累計 105%，一般無擔保 103%，便利類別 120%。
- 原手冊寫「曾估值 320 億美元」：本次未查證，本文刪除。
- 第四輪的來源是交易所新聞頁轉述信託公告，未直接讀信託原始公告。
