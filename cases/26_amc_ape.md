# 案例 26：AMC 與 APE 的轉換價差（2022-08 ～ 2023-08）

> **一句話**：AMC 發給股東一種優先股單位 APE，經濟上等於一股 AMC 普通股，卻長期以不到半價交易。價差能不能收斂，取決於 Delaware 衡平法院准不准轉換。法院擋了半年，借券費又高，套利者看得到價差，卻很難賺到。

| 項目 | 內容 |
|---|---|
| 接縫 | 公司章程限制普通股的授權股數（散戶股東不願增資）＋ 優先股不受同一表決限制 → AMC 用 APE 繞過股東，增發等同普通股的證券；兩種證券的價格就此脫鉤 |
| 強制流來源 | 轉換完成時，APE 依約自動變成普通股；轉換前要先經股東會與法院 |
| 量級 | 2023-02-07：AMC 6.80 美元、APE 3.11 美元 |
| 不看價格的一方 | 公司：要把 APE 換成普通股，才能繼續增資 |
| 天然對手方 | 持有 AMC 普通股的散戶（不願被稀釋）vs. 買 APE、空 AMC 的套利者 |
| 規則風險 | Delaware 衡平法院的維持現狀命令與和解審查，決定能不能轉換、什麼時候轉 |
| 查證狀態 | ✅ 發行、法院程序、反分割與轉換日期已對 SEC 申報與法院文件；⚠️ 折價只找到少數時點的報價，最後一天的收盤價未證實 |

## 2. 機制

- **制度**：AMC 普通股的授權股數用完了，要增加授權得經股東會同意，而散戶股東長期反對稀釋。APE 是優先股的存託憑證，董事會可以在已授權的優先股額度內自行發行。這等於把「增資表決」變成「轉換表決」，延後處理。
- **為什麼價差不收斂**：一單位 APE 未來可換一股（分割前）普通股，理論上應該等價。但 (1) 轉換需要股東會通過，又被法院擋住，時程不確定；(2) 套利要放空 AMC，可是 AMC 的借券使用率接近 100%，借券費很高；(3) 轉換本身會稀釋普通股，AMC 自己的價格在轉換時也會往 APE 靠，而不只是 APE 往上漲。
- **法院的角色**：維持現狀命令讓股東會的結果不能執行。2023-07-21 不准和解、2023-08-11 准了修正版，每一次法院的決定都直接在價差上造成跳動。

## 4. 我的解讀（草稿，待討論）

1. **這個價差定價的是法院，不是 AMC 的電影院生意。** 2023 年 2 月到 8 月，價差的每一次大跳動都對應衡平法院的程序（維持現狀命令、和解宣布、不准和解、核准和解）。跟 Twitter（案例 20）一樣：可以交易的是審判日曆。
2. **看得到的價差不等於賺得到的價差。** APE 長期打五折，但套利一側要放空一檔借券使用率接近 100% 的迷因股，還要承受法院把轉換延後的時間風險，借券成本會隨等待時間一直累積。這是「套利的極限」（limits to arbitrage）的教科書例子：價差大，是因為持有它的成本大，不是因為沒人發現。
3. **規則制定者（法院）在保護的是程序，不是價格。** 法院兩次擋 AMC，理由都是程序（股東權益、和解的放棄範圍），從來沒有評估價差該不該存在。對 prop desk：在法院主導的事件裡，要預測的是法院的程序要求（多久、要補什麼），不是它對經濟結果的看法。

## 5. 限制與未證實

- **原手冊寫「2023/8/24 完成轉換（含 1:10 反分割）」**。依 AMC 8-K，反分割在 **2023-08-24** 00:01 生效，APE 轉換在 **2023-08-25** 開盤前完成。
- **原手冊寫「遭部分股東訴訟（Delaware），一度阻擋」**，正確；維持現狀命令日期是 2023-02-27。
- **原手冊要的「折價幅度在幾個時點」**：只找到 2023-02-07 與 2023-04-03 有可靠的雙邊報價。2023-08-11 核准和解前後、2023-08-24 APE 最後一天的收盤價，沒有找到一手來源，**未證實**；本文沒有填。
- 2022-12-22 宣布轉換提案當天的 APE 漲幅，有報導寫 45%，但沒有對到收盤資料，本文沒有列入。
- AMC 借券使用率「超過 99%」與借券費，來自 S&P Global 與 EquiLend 的分析摘要，本文只做定性描述。
- 2023-08-14 的漲跌幅是盤中數字（Seeking Alpha 寫 AMC −37%、APE +15%；Reuters 寫 AMC −35%）。
