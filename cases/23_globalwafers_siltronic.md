# 案例 23：環球晶收購 Siltronic 破局（2020-11 ～ 2022-02）

> **一句話**：德國經濟部不必說「不」，只要在 2022-01-31 的合約截止日前不發核准，這筆 43.5 億歐元的收購就自動失效。監管審查期限本身就是事件日，而且事前就知道是哪一天。

| 項目 | 內容 |
|---|---|
| 接縫 | 收購合約有一個固定的完成截止日（long-stop date），德國外資審查的法定期限卻可以因為「補件」暫停計算。兩套時鐘不同步，監管機關只要讓自己的時鐘停住，就能讓合約的時鐘先走完 |
| 強制流來源 | 公開收購的條件沒有在期限內全部達成 → 收購失效，已應賣的股份退回原股東，環球晶依合約付 5,000 萬歐元分手費 |
| 量級 | 收購價每股 145 歐元，總額約 43.5 億歐元；環球晶自己在市場上另外買進 Siltronic 13.67% |
| 不看價格的一方 | 公開收購期間應賣的股東：股份在收購失效前不能賣，失效後一次退回市場 |
| 天然對手方 | 併購套利者：在價差裡押注「會核准」 |
| 規則風險 | 高：德國經濟部表示若再次提出收購，會重新審查。審查結果取決於政治判斷（科技主權），無法從法條推算 |
| 查證狀態 | ✅ 時程、價格、分手費已對兩個以上獨立來源；環球晶股價為 FinMind 自行計算；⚠️ Siltronic 破局當天收盤價未取得（見第 5 節） |

## 2. 機制

德國外資審查（依《對外貿易與支付條例》AWV）有法定期限：初審 2 個月、深入審查 4 個月，最多再延 4 個月；期限屆滿未表態就視為核准。但這個期限在主管機關「要求補件」時會暫停計算（[Noerr](https://www.noerr.com/en/insights/no-fdi-clearance-takeover-of-siltronic-by-globalwafers-fails)）。收購合約的截止日卻是固定的。所以經濟部只要在 2021-12-10 發一份補件函，把自己的時鐘停住，就不用正式否決：合約的時鐘先走完，交易自己失效。經濟部官方說法是「無法在期限內完成所有審查步驟，尤其中國的核准來得太晚」。背後的人性與政治層是科技主權：車用晶片短缺之後，德國對半導體供應鏈轉為保守（[CNBC](https://www.cnbc.com/2022/02/01/globalwafers-bid-for-siltronics-fails-amid-tech-sovereignty-concerns-.html)）。

## 4. 我的解讀（草稿，待討論）

1. **監管審查期限本身就是可以排進行事曆的事件日。** 合約截止日（2022-01-31）一年前就寫在收購文件裡。真正的資訊是「主管機關有沒有在倒數階段暫停時鐘」：2021-12-10 的補件函才是實質判決，比破局早七週。對 prop desk 來說，要追蹤的是監管程序的狀態（補件、暫停、延長），而不是等最後的公告。
2. **破局當天目標公司上漲，代表價差早就把破局價進去了。** 1 月中 Siltronic 就已大幅低於 145 歐元，破局當天反而 +4% 左右。可以交易的窗口在「時鐘被暫停」到「截止日」之間，不在截止日當天。
3. **收購方才是破局日的強制流所在。** 環球晶失去的是成長故事，不是分手費（5,000 萬歐元相對市值很小），但台股剛好遇到春節休市，賣壓集中在 02-07 一天釋放。休市期間發生的事件，回到台股會集中成一個缺口，這在其他跨時區併購案也會重演。
4. **接縫會往「同一接縫的另一個出口」移動。** 歐洲收購走不通，資金改去美國建廠（2022-06），並以美國晶片法案補助為條件。監管關掉的是「用併購取得產能」這條路，不是需求本身。

## 5. 限制與未證實

- Siltronic 2022-02-01 收盤價與收盤漲幅未取得一手資料，只有盤中數字（Reuters 11:26 GMT +4.8%、CNBC「約 4%」、Taipei Times「最多 +3.9%」）。
- 原手冊寫「2020/12 宣布以約 37.5 億歐元收購」：37.5 億歐元是 125 歐元時的初始金額；2021-01 已加價到 145 歐元、總額約 43.5 億歐元。破局時應以 145 歐元為準。
- 原手冊把「赴美國德州建廠」寫成破局後立即的反應。實際上破局後一週（02-06）宣布的是 1,000 億元新台幣擴產計畫，德州廠是 2022-06-27 才宣布。
- 合約截止日 2022-01-31 是收購條件中的完成期限（Wacker 新聞稿：「完成交易的期限 2022-01-31」），不是德國法定審查期限。兩者容易混淆。
- 交易總額各媒體寫法不同（40 億 ～ 43.5 億歐元、約 49 億美元），差異來自匯率與口徑；本文採 145 歐元 × 股數 ≈ 43.5 億歐元。
